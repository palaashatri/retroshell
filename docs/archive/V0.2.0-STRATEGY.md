# v0.2.0 Strategy — Path to Bare Minimum Functionality

**Goal:** Reach v0.2.0 with Spotlight rendering + basic visual QA  
**Timeline:** This session (continuous iteration)  
**VM Target:** UTM Ubuntu aarch64 @ 192.168.64.15 with screenshots  

## What is v0.2.0?

The minimum viable version that has:
1. **Spotlight rendering** — Visible search UI with results
2. **Working theme system** — Light/dark mode switching in Settings
3. **Defect fixes** — At least Defect J (buttons) partially fixed
4. **Fresh screenshots** — All current features documented visually
